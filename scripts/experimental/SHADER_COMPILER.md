# Compilador de shaders experimental

`get_shader_compiler.ps1 -Destination <carpeta nueva>` descarga el CAB fijado del SDK de Windows desde Microsoft, verifica su SHA-256 y usa `expand.exe` de Windows para extraer `fxc.exe` y `d3dcompiler_47.dll`, verificando ambos archivos. `-Cabinet` acepta una copia previamente descargada, que se verifica igual. El CAB ocupa 18.745.734 bytes; no se instala el SDK.

Se probó la descarga y extracción con Windows PowerShell 5.1. El `fxc.exe` obtenido y su DLL coinciden byte por byte con los utilizados en la construcción gráfica anterior. Se usó esa copia para ejecutar `build_shadow_shader.ps1`, que generó el shader con el hash esperado (`3BE64E932AC65FB2A41E3D379B053A530B1593158CE0FDD7A81185821C0A61C5`).

Los términos aplicables siguen pendientes de revisión. El [documento de licenciamiento de Visual Studio 2022](https://visualstudio.microsoft.com/wp-content/uploads/2023/07/Visual-Studio-Licensing-Whitepaper-July2023.pdf) describe restricciones de uso de Build Tools; no basta que la descarga sea técnicamente posible para concluir que este flujo se puede ofrecer a todos los usuarios. El compilador de shaders del SDK y los componentes de Build Tools requieren revisar sus términos específicos. Este script es una prueba local, no una conclusión legal ni un instalador publicado.

`build_graphics_plugin.ps1` acepta `-Toolset <carpeta>` para compilar la DLL con el conjunto portable y `-Fxc` para usar el compilador descargado. `get_llvm.ps1` incluye `llvm-mt.exe`, necesario para los manifiestos de Windows. Las fuentes ReXGlue se descargan como ZIP de una revisión fija y se verifica su SHA-256 antes de extraerlas. Los dos parches se aplican con `apply_exact_patch.ps1`, que exige coincidencia exacta del contenido. Con Git fuera de `PATH`, Windows PowerShell 5.1 obtuvo las fuentes y compiló las 37 etapas usando el conjunto portable. El shader conservó el hash esperado. La DLL resultante tiene SHA-256 `1092F4AFFB30CF6E21AA697B45D39684AF696A7E359734A587501DA7662C5912`; el hash puede variar entre construcciones. En una prueba aislada anterior, una DLL construida con estas herramientas inició el juego y el proceso respondió a los 20 segundos. No se comprobó visualmente un partido ni las sombras; `prepare_playable.ps1` todavía exige el hash de la DLL anterior. La compilación y la prueba no se hicieron en un Windows limpio.
